# AI-Based Requirements Change Impact Analyzer

## Objective
Develop an AI-powered system that identifies potentially
affected Jira user stories when business requirements change.

## Core Features
1. Business requirement change detection
2. Semantic search of Jira issues
3. Dependency graph analysis
4. AI-generated user story updates
5. Human approval and Jira integration

## Technology Stack
- Python
- Sentence Transformers
- NetworkX
- Large Language Models
- FastAPI
- React
- Jira REST API
